# Deal photography

These 24 images (800 × 960) are the client's own deal artwork, copied from the
live site `adequatesafaris.com` (`/wp-content/uploads/...`) so the new
`/deals/*` pages match the WordPress site that customers already recognise.

No Creative Commons attribution applies — they belong to Adequate Safaris.
If the client supplies updated artwork, drop it here with the same file name
(`public/deals/<category-slug>.jpg|webp`) and it will be picked up
automatically; nothing is generated from these files at build time.

They are intentionally *not* run through `scripts/generate-image-variants.js`,
which only manages the `public/cards` and `public/hero` sets.
